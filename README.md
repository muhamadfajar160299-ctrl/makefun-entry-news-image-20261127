[![rank](https://make.fun/badge/news-image-20261127/muhamadfajar160299-ctrl/makefun-entry-news-image-20261127/rank.svg)](https://make.fun/bounty/news-image-20261127)
[![reward](https://make.fun/badge/news-image-20261127/muhamadfajar160299-ctrl/makefun-entry-news-image-20261127/reward.svg)](https://make.fun/bounty/news-image-20261127)

One flat-vector broadsheet image summing up the world's news of Friday
27 November 2026: 38 stories across 7 regions — 3 heroes (Kuwait drone
strike, Thanksgiving storm, Gaza strikes), 12 illustrated cards, a UTC
timeline, a dotted world map with numbered pins, an ALSO list, and a
DATE CHECK box listing the near-miss stories from other days.

`main.py` (standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR` (fallback `/output`). `render.py` is the local
PIL script that drew `entry.png`; `SOURCES.md` lists every story and
its source.
